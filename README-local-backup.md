# CyberSafe ID — GitHub Actions build starter

This is a **minimal starter project** that verifies the GitHub Actions APK/ZIP delivery flow. It is not the full CyberSafe ID v5/v6 feature set and does not perform real APK malware scanning.

## Build APK and ZIP on GitHub

1. Create/open your GitHub repository.
2. Upload the contents of this folder to the repository root. Keep `.github/workflows/build-android.yml`.
3. Commit/push to `main` or `master`, or open **Actions** and run **CyberSafe ID - Build APK and ZIP** manually.
4. Open the successful workflow run and download these artifacts:
   - `CyberSafe-ID-debug-apk` — installable debug APK.
   - `CyberSafe-ID-source-zip` — Android Studio source project ZIP.

## Important

- The APK is a debug build, not a Play Store release.
- The workflow has not been executed against your GitHub repository here; confirm that the run finishes successfully.
- This starter screen is educational only. It does not include the earlier full curriculum, malware simulation, or real app/APK risk scanner.
